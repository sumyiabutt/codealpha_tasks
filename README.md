1. Hangman Game

Overview:

Hangman is a text-based word-guessing game developed using Python. The player attempts to guess a hidden word by entering letters one at a time.

Key Features:

- Random word selection.
- User input for letter guesses.
- Tracking of correctly and incorrectly guessed letters.
- Display of the current word progress.
- Limited attempts to guess the word.
- Win and lose conditions.

Python Concepts Used:

- Variables and data types.
- Strings and lists.
- Loops and conditional statements.
- Functions.
- User input and output.
- Random module.

Learning Outcome:

This project helps develop logical thinking and provides practical experience with loops, conditions, string manipulation, and interactive program design.

- Display portfolio information in a readable format.

Python Concepts Used:

- Dictionaries and data structures.
- Variables and arithmetic operations.
- Loops and conditional statements.

- File handling, if implemented.

Learning Outcome:
